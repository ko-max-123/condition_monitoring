# コンディション観測レポート v4

## 今回の変更

- v3のレポート本文・章構成・グラフのデータ期間は維持。
- 全体の文字サイズを引き上げ、特に小さかった表・注記・グラフ凡例・数値の可読性を改善。
- 「内部・外部・総合スコア」は全幅グラフとし、縦軸を5.0〜6.7に拡大し、**目盛りを0.1刻み**に変更。0.5刻みの線を少し強く表示。
- 線の見分けのため内部＝実線と丸、外部＝破線とひし形、総合＝太線と四角を採用。
- グラフ直下に各月の正確な数値表を追加（元Excelの計算結果から再集計）。
- タブレットでの見せやすさを考慮し、当該グラフを横幅いっぱいに配置。スマートフォンのみ横スクロールで拡大グラフを表示。

## 開き方

`index.html` をブラウザで開きます。ネット接続やライブラリは不要です。`assets/report.css` の相対位置を維持してください。

## 注意

縦軸は0〜10を表示するのではなく、値の違いを確認できるように5.0〜6.7へ拡大しています。見た目の変化は実際より大きく感じられるため、数値表もあわせて確認してください。

このレポートには個人的な観測情報が含まれます。GitHub Pages等に公開すると第三者が閲覧できる可能性があるため、公開先に注意してください。
