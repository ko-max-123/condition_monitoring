# ① コンディション記録 Webアプリ

元のExcel『体調・メンタル観測ログ』の入力を置き換えるWebアプリです。

## 動作
- 1〜10を数字ボタンで直接選択。スライダーなし。
- 日付単位で新規保存・既存記録編集。未入力は未入力として保持。
- 元Excelの内部・外部・総合スコアを算出。負荷項目は逆転得点。
- Googleスプレッドシート（Googleドライブ内・非公開）に保存。
- CSVによる既存120日分の取り込みとCSV書き出し。
- PC/スマホ/タブレット対応。個人名を表示しません。

## 設置手順（Google Apps Script）
1. https://script.google.com/ から新しいプロジェクトを作る。
2. `コード.gs` の中身を `Code.gs` に置き換える（または既存 Code.gs を削除して同名作成）。
3. `Index.html` というHTMLファイルを追加し、本ファイルの全文を貼り付ける。
4. （任意）プロジェクトの設定でタイムゾーン `Asia/Tokyo` を指定する。`appsscript.json` と同じ内容です。
5. Apps Scriptエディタで関数 `setupApp` を選び **1回だけ実行**。Googleの許可画面を承認する。実行ログのスプレッドシートURLが保存先です。
6. [デプロイ] > [新しいデプロイ] > [ウェブアプリ]。**次のユーザーとして実行：自分、アクセスできるユーザー：自分のみ** で公開。
7. 表示された `/exec` URLを開く。数字ボタンを選んで保存できるか確認する。
8. 「04 記録一覧」のCSV取り込みから別添 `観測ログ_移行用_非公開.csv` を読み込む。既存日付は上書きされずスキップされます。

> 他人に共有したい分析サイトは②だけ。こちらのアプリやスプレッドシートは公開しないでください。

## ブラウザ上でのプレビュー
`Index.html` を直接開くこともできます。この場合、上部に「デモモード」と表示され、操作内容は現在の画面内だけの一時記録で、**Googleドライブには保存されません**。

## 採点互換性
- 内部：気分 / 身体調子 / 11-不安 / 11-イライラ / 11-疲労 / 集中力 / やる気 / 安心感の平均。
- 外部：睡眠時間（7.5h中心）・睡眠の質・11-起床時疲労・食事安定・運動（30分満点）・日光（15分満点）・11-作業負荷・11-対人ストレス・カフェイン（0杯で10点、1杯ごとに2点減）の平均。
- 総合：内部と外部の平均。各平均は小数第1位に丸め、Excelと同じ方法です。
- **部分入力の注意**：元Excelでは内部の未入力に一部自動加算され得る式でした。本アプリは未入力の評価項目を平均分母から除外します（全入力時は元式と同値）。

## セキュリティと制約
- Google Apps Script / Googleドライブの無料枠・実行回数制約が適用されます。
- 個人で閲覧・操作する設定以外でデプロイしないでください。
- CSVには自由記述を含むため、GitHubや公開フォルダへアップロードしないでください。
- データはシートに保存されるため、必要に応じてGoogleドライブのアクセス権限・バックアップを確認してください。
- 時間・分は数値入力、1〜10項目はクリック選択です。
